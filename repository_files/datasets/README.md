# Dataset placement

Clinical datasets are not redistributed in this repository.

Extract IDRiD under:

```text
datasets/IDRiD/
```

The discovery code searches recursively, so the original IDRiD nested folder
structure is supported. Download IDRiD from its official source:

https://idrid.grand-challenge.org/Data/

The included `demo_assets/synthetic_fundus.png` is only for interface and
engineering checks. It must not be used to report clinical performance.
